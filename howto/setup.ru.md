# Настройка прошитого узла

Разовая настройка через serial-консоль (или удалённо через mesh, через админ
CLI, если узел уже есть в ваших контактах). Настройки сохраняются между
перезагрузками и обновлениями прошивки.

## 1. Подключаемся к консоли

Откройте USB-serial порт платы на **115200 бод** (нажмите Enter, чтобы
увидеть приглашение):

```sh
pio device monitor -b 115200
# или: screen /dev/ttyUSB0 115200   (выход: Ctrl-A k)
```

## 2. Настраиваем WiFi, IATA, проверяем

Всё делают три команды:

```
set wifi.ssid ВашаСеть
set wifi.pwd ВашПароль
set mqtt.iata KVX
```

- `iata` — код локации в теме MQTT (`meshcore/<IATA>/<pubkey>/...`); до его
  установки публикация выключена. Используйте код, о котором договорилась ваша
  сеть (для Кировской сети: `KVX`).
- Брокер (meshcoretel) **включён по умолчанию** — серверы и учётные данные
  настраивать не нужно.

Проверяем:

```
get mqtt.status
```

Сразу после `set mqtt.iata` будет примерно так:

```
> wifi:up ntp:wait iata:KVX meshcoretel:wait eu:off us:off tx:off pkt:0 pub:0 drop:0 q:0/8 heap:118000
```

Через ~30–60 секунд должно стать:

```
> wifi:up ntp:up iata:KVX meshcoretel:up eu:off us:off tx:off pkt:12 pub:12 drop:0 q:0/8 heap:110000
```

Значения полей: `wifi` — станция, `ntp` — часы синхронизированы (публикация
включается только после `up`), состояния брокеров —
`up`/`wait`/`retry`/`backoff`/`off`/`invalid-iata`, `pkt` — услышано пакетов,
`pub` — опубликовано, `drop` — потеряно (очередь полна / брокер недоступен
> 60 с), `q` — глубина офлайн-очереди, `heap` — свободная память.

Если `pkt` растёт, а `meshcoretel:up` — всё работает. Проверьте, что узел
появился на meshcoretel.ru под вашим IATA.

## 3. Дополнительные настройки

```
set mqtt.tx advert      # публиковать и свои реклама-пакеты (видимость на картах)
set mqtt.raw on         # публиковать сырые кадры (больше трафика, по согласию)
set mqtt.packets off    # остановить публикацию разобранных пакетов (вкл. по умолчанию)
get wifi.status         # ip, rssi, качество сигнала
mqtt recover            # пересобрать WiFi + соединения с брокерами с нуля
reboot                  # настройки сохраняются
```

Радиопараметры должны совпадать с региональными настройками вашей сети —
следуйте рекомендациям meshcoretel.ru для региона (KVX); не копируйте
радиопараметры со страниц других регионов.

## Примечания

- **Питание**: наблюдатель намеренно не спит (WiFi должен оставаться
  подключённым). Узлы с включённым `powersaving_enabled` тоже не засыпают,
  пока активен uplink.
- **Удалённое администрирование**: когда узел знает ваш админ-контакт, все
  эти команды работают и через mesh (TXT admin CLI), например `mqtt recover`
  из дома. Одно ограничение: вывод `get mqtt.status` длинный — читайте его
  по serial.
- **Безопасность**: пароль WiFi хранится на устройстве (по CLI не
  возвращается); учётные данные meshcoretel — общедоступные по дизайну
  брокера. Физический доступ к узлу = доступ к его конфигурации.
